# Dashboard-2 Project

## Stack
- HTML, CSS, JavaScript (Vanilla)
- No framework or build tool

## Conventions
- Semua file utama berada di root: `index.html`, `style.css`, `script.js`
- Gunakan komentar yang jelas pada setiap fungsi di `script.js`
- CSS ditulis mobile-first

## Tujuan Proyek
Dashboard sederhana berbasis web statis.
